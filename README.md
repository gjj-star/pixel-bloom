# PixelBloom · 像素绽放

一个会流动、生长和繁衍的像素生态沙盒。用沙、水与石头塑造地形，播下种子培育花草和树木，采摘果实、喂养小鸡，并观察这个微型世界自然演化。

## 🌱 在线游玩

**[点击进入 PixelBloom](https://lutingxie8-ship-it.github.io/pixel-bloom/)**

无需安装或注册，使用现代桌面浏览器即可开始。游戏进度保存在当前浏览器中，重要作品可以通过游戏内的导出功能备份。

## 游戏特色

- 基于密度的沙、水、盐与酸等粒子运动，以及液体找平和材料反应。
- 从种子逐节生长的花草、果树、霸王花、蘑菇、仙人掌与耐湿树木。
- 树木会避开障碍、吸水生长、结果并自然落果，植物积水过多会枯萎。
- 小鸡可以进食、成长、互动、产蛋和孵化，鸡群上限为 10 只。
- 支持撤销、自动保存、多作品管理、文件导入导出和预设场景。
- 提供可跳过的新手引导，桌面和小屏幕均可操作。

## 当前材料

- 沙子：受重力影响，可以沉入水中。
- 水：受重力影响，遇到阻挡后向两侧流动。
- 石头：静止不动，用来搭建容器和障碍物。
- 木头：静止且可燃，着火后会向附近木头传播。
- 火焰：向上运动，能够点燃木头，被水熄灭后可能产生烟雾。
- 烟雾：向上漂移，经过一段时间自动消散。
- 种子：像粉末一样沉降，接触水后先吸水，接触承托面后吸收同类种子团，逐节长出花草和花苞。
- 小树种子：主干持续向上，目标高度为离根点 108～130 格，吸水可额外增加少量高度，始终受屏幕 3/4 高度上限约束。从树高中段开始，最多分化四层左右交错的侧枝，下层较长、上层收拢，沿缓弯路线伸展。主干与各枝端逐步长出大小不同的扁圆叶簇，树叶上浅下深、边缘留有空隙。树干每 3 帧、树枝每 5 帧推进一格；吸水会增加树干和枝条的绘制宽度，树干粗度最多为初始的 3.8 倍，并向枝端收细。
- 霸王花种子：浇水发芽后长出较低的承托茎和宽叶，再逐渐展开五瓣红色大花；花冠直径缩为上一版的一半，保留浅色斑点和深色花盘，与高大的小树拉开体型差异。
- 树叶：小树生长产生的内部材料，可被火点燃、被酸腐蚀，不提供独立绘制按钮。
- 果实：成熟树冠的下缘会逐颗结出青果，逐渐转黄、变红，再错时自然掉落；承托叶片被擦除、燃烧或腐蚀时也会掉落。每个叶簇最多结 3 颗，整棵树累计最多结 12 颗。
- 落果：受重力影响，可以拨开树叶、沉入水中，在沙土、树干或平台上停住；停留一段时间后变褐并消失，不会自动变成种子或无限繁殖。
- 草：种子的伴生支撑结构，吸收相邻的水获得继续长高的能量，沿斜上方弯曲并少量分枝；周围过密时会暂停扩张。
- 花：种子的主要生长结果，播种后先长高根茎，达到生长年龄后先出现小花苞，再沿不同枝端逐帧展开，不单独出现在材料面板中。
- 蒸汽：由水和火接触产生，向上运动，能量耗尽或接触石头后冷凝回水。
- 金属：静止不动，被电流激活后会向相邻金属传导。
- 盐：像粉末一样沉降，接触水后逐渐溶解。
- 酸：像液体一样流动，会腐蚀木头、植物、盐和少量金属。
- 电流：短寿命火花，可激活金属并在空隙和水中传播。

电流传播有明确的生命周期和每帧一次的复制上限，避免一个初始火花指数式填满画布。

## V0.3 反应链

```text
种子团 + 水 -> 种子团消失 -> 弯曲草茎伴生、立即开花
草（伴生支撑） + 时间/水 -> 弯曲分枝
种子能量 + 枝端空间 -> 持续开花
火 + 木头/植物 -> 燃烧传播 -> 火焰与烟雾
火 + 水 -> 蒸汽上升 -> 冷凝 -> 水
```

## 关键数据结构

```text
cells[i]   -> 第 i 个格子中的材料编号
energy[i]  -> 火焰/气体寿命、木头燃烧时间或植物生长能量
moved[i]   -> 本轮更新中这个格子是否已经移动过
```

一帧先更新向下运动的沙子和水，再更新向上运动的火焰和烟雾，最后把材料颜色写入 Canvas 的 `ImageData`。

## 操作

### 界面布局

- 顶部固定提供“保存作品”“我的存档”和“新手引导”入口；“场景与世界”默认折叠，展开后可更换预设、清空或重置，危险操作仍需确认。
- 桌面采用左侧材料、右侧画布布局。材料按“地形与水／种植／反应与工具”分组，选中状态同时提供视觉高亮和无障碍标记。小屏幕自动变为上下布局。
- 画布上方保留笔刷、速度、喷洒、采果、小鸡、喂果、撤销和暂停；下方显示当前工具与操作反馈。“世界统计与性能”和“操作说明与快捷键”默认折叠，可随时展开；果子库存和小鸡数量用一行显示，不再保留果篮和成就板块。
- 本次只调整页面布局与材料排列，模拟网格仍是 360×220，材料物理、生长速度、存档与快捷键规则不变。

### 可跳过的新手引导

- 首次打开时显示非阻塞欢迎卡片，由玩家选择开始或跳过；不会自动清空、创建示例或改写存档。顶部“新手引导”按钮可随时重新打开。
- 六步依次介绍铺沙、播种、少量浇水、观察生长、采果、保存。当前工具会高亮，点击引导中的工具按钮才会切换材料；每步支持直接略过，等待植物或果实时也不强制停留。
- 操作提示只根据真实绘制、生长和采集更新。“已绘制水”不代表成功发芽；保存步骤只确认打开管理窗口，实际保存结果仍以存档窗口提示为准。
- 练习直接发生在当前画布，玩家亲自绘制的改动与普通操作一样可撤销，也会参与自动保存。引导本身不生成演示材料；需要独立练习时，可自行备份作品后创建空白场景。
- 跳过或完成后，在当前浏览器记住选择，下次不自动展开；该偏好与世界存档分开保存。浏览器禁止本地存储时，仅保证当前页面能关闭引导。

### 小鸡与果子喂食

- 成鸡（成长达到 95%）在干燥、有承托、饱腹至少 20 且未进食／被摸摸时，累计 1200 个模拟步后在脚边产蛋，消耗 20 饱腹，不额外扣库存。每只最多保留 2 枚，全场最多 8 枚；空间不足时等待，暂停时停止积累。鸡蛋为独立像素实体，地面移除会下落，不阻挡材料。
- 普通绘制模式靠近鸡蛋可查看孵化百分比，点击收集并累计数量；鸡蛋近距离点击优先于摸小鸡，熟果仍优先于鸡蛋。一次按下只收一枚，拖走不会绘制；橡皮擦和专用工具不触发收蛋。母鸡下蛋后留在原地蹲伏孵蛋，不再闲逛或跟随光标，仍可喂食；收走蛋或孵化成功后恢复活动。只有母鸡守在蛋旁、干燥且有承托时才累计孵化进度，累计 2400 模拟步后在旁边空地出生；出生空间不足时等待。鸡群达到 10 只后停止产蛋和孵化。暂停模拟也停止计时。收集可撤销，孵化进度和收蛋数量随世界保存；旧蛋从零进度开始。清空移除地上的蛋但保留已收数量，重置清零。
- 普通材料绘制模式下，靠近小鸡会显示互动指针和操作提示：有库存且小鸡没吃饱时点击喂一颗；没果子或已吃饱时点击摸摸；正在进食或被摸摸时等待，不扣果子。悬停不执行操作，按下后整次拖动最多互动一次，也不会移开后画出材料。触屏可直接点小鸡。熟果重叠时优先采摘，橡皮擦、批量采果及小鸡／喂果专用工具保持优先。
- 已移除果篮、收获成就、里程碑和入篮动画。保留采果工具与历史收获统计；可喂果子 = 累计收获 - 已喂数量，喂食不会倒扣历史收获。
- 点击“🐤 小鸡”再点干燥空地放置，自动寻找点击位置下方的承托面，最多 10 只；一次点击／拖动只放一只。小鸡会缓慢走动、停歇、在边缘和障碍前转身；承托面被移除后会下落。
- 先采集成熟树果或落果，再选“🍎 喂果”点击小鸡附近。一次点击／拖动只消耗一颗果子，进食时停步并显示爱心。库存为空、点空白或小鸡已经吃饱时不扣果子。饱腹度随模拟时间下降，暂停时不消化。
- 小鸡交替走动、低头啄地、回头理毛和闭眼休息，吃饱后更容易休息；啄地只是动作，不会自动吃掉世界里的果实。吃果时有低头、果粒与爱心，吃完后短暂满足地扑翅。
- 使用“小鸡”工具点已有小鸡可摸摸它，显示闭眼和扑翅反馈，不额外生成小鸡、不消耗果子；正在吃东西或已经被摸摸时不重复触发。摸摸也可撤销。
- 喂过且尚未吃饱的小鸡，能在“喂果”工具启用、库存有果子时短距离追随鼠标光标（最多 48 格、近似同一高度）。一次只吸引最近的一只，仍受地形、水边、悬崖和其他小鸡阻挡；靠近不会自动扣果，必须点击喂食。触摸设备仍用点击喂食，不依赖悬停。移开光标或切换工具即可停止引导。
- 动作状态和剩余时间随世界存档保存；旧存档的小鸡默认从走动开始。鼠标位置不写入存档，暂停模拟时走动、消化和动作计时都暂停。
- 放置和喂食可按 Z 撤销；小鸡位置、饱腹、进食状态和已喂数量接入自动保存、作品库及文件导入导出。旧存档默认没有小鸡，历史收获可直接用来喂食。
- 小鸡随模拟时间成长，吃饱时积累速度为普通的 1.6 倍；暂停时停止成长。成长分幼雏、少年鸡（35%）、成鸡（95%），至少喂过一颗果子才可进入少年期，至少三颗才可完全长成。完整成长需积累 7200 个成长单位，实际等待受模拟速度、饱腹和场地空间影响；不是每次喂果立即跳大一截。
- 体型从初始逐渐增大到最多 1.7 倍，脚底位置不变；颜色由黄色绒毛渐变到固定的米白、棕褐或灰斑，随后出现尾羽、鸡冠。羽色在出生时选定，读档和刷新不会重抽。碰撞空间随体型增加，头顶或身边拥挤时暂缓长大，腾出空间后继续。成鸡仍保留原有摸摸、喂食和跟随行为。
- 成长进度、营养记录和羽色支持撤销、自动保存、作品库和导出；旧版小鸡从幼雏成长进度开始，已喂数量保留，羽色按编号固定补齐，不会读档后突然变大。
- 清空移除小鸡但保留库存和历史收获，重置／创建场景移除小鸡并清零。小鸡是独立实体，不阻挡粒子、不自动偷吃树果，目前不含繁殖或伤病系统。

### 玩法与预设场景

- 项目仅保留自由沙盒，全部材料、种植养护、采果和收获统计均可自由使用，不设置挑战任务。
- 五个预设：材料实验室（原有沙水、木屋、电路）、空白世界（仅底部边界）、池塘湿地（水池、沙岸、柳树和红树林种子）、花园苗圃（沙床与花种）、果园（三处普通果树播种点）。植物由种子正常生长，不预先生成成熟树。
- 选择场景只是预览说明，点击“创建此场景”并确认后才替换世界、清零收获。可按 Z 撤销，命名存档不会删除；“重置”重新创建当前场景来源，“清空”只擦掉当前画布并保留统计。
- 场景来源随自动保存、命名存档、文件导出和撤销恢复，作品卡片显示对应信息。旧挑战存档仍可读取，任务和模式字段会忽略，不改变植物与收获统计。预设名称表示场景来源，不限制后续编辑。

- 按住鼠标或手指绘制材料。
- 普通绘制模式下，靠近成熟树果或落果（5 格范围）鼠标自动变成抓手，点击即可采摘，触摸屏也支持直接点熟果。青果不触发，橡皮擦、小鸡和喂果工具优先，不被自动采摘抢占。悬停不扣果，成熟状态变化后即使鼠标不动也会更新抓手。
- 采摘从按下开始锁定本次拖动，拖到空白处不会画出材料；从普通绘制开始的拖动则不会突然变成采摘。每次采摘拖动只保存一步撤销，点不到熟果不会重复加库存。
- 「🧺 批量采果」或 `C` 仍作为可选快捷方式保留，范围跟随笔刷大小；选择材料或再次按 C 返回普通模式。直接采摘的近距离范围不随笔刷放大。
- 状态栏分别显示树上采摘、落果拾取与累计总数。一整次拖动采集算一步撤销，点空白或青果不产生撤销记录。统计随存档保存，旧存档没有统计时从零开始；“清空”保留已收集数量，“重置”将统计清零，均支持撤销。
- 空格键暂停或继续。
- 数字键 `1`～`6` 选择沙子、水、石头、木头、火焰、种子。
- 数字键 `0` 切换到橡皮擦。
- 数字键 `7`～`9` 选择金属、盐、酸；按 `E` 选择电流。
- 草和花是种子的内部生长结果，不提供单独的绘制按钮。
- `Z` 撤销上一步绘制、清空、重置或读档操作，最多保留 12 步。
- `R` 切换标准笔刷和随机喷洒笔刷。
- 速度可以切换为 `0.5×`、`1×`、`2×` 或 `4×`。
- “保存作品”和“我的存档”打开同一管理窗口，管理期间暂停模拟，关闭后恢复之前的暂停／运行状态。数据不会上传。

## 存档与作品管理

- 每 20 秒自动保存一次当前世界（正在绘制、管理存档或上次世界尚未确认时暂缓），切到后台时也会尽力保存。浏览器直接退出不能保证最后一次写入完成，重要作品请手动保存或导出。
- 发现上次自动存档时，页面显示“继续上次世界／从当前世界开始”；选择之前不会用初始示例覆盖旧自动存档。自动存档只有一份，会滚动更新；命名作品互相独立，不被自动覆盖。
- 输入作品名称可另存新作品；作品卡片显示缩略图与保存时间，支持读取、导出、改名、覆盖、删除。覆盖和删除需确认；删除本地作品不可撤销，已导出的备份文件不受影响。读取会替换当前画布，但可按 Z 撤销恢复。
- 导出当前世界或指定作品为 JSON，导入前检查版本、网格尺寸、材料编号、数组范围和植物结构，最大文件 20 MB。导入只读取到画布，不自动新增命名作品，需要时点击“另存为新作品”。不要把导出文件当图片打开，它包含完整世界状态。
- 新作品和自动存档使用 IndexedDB；旧 localStorage 单槽存档仍在列表中只读展示，不自动删除。已有旧版果实时间兼容逻辑保留。
- 浏览器清理站点数据、隐私模式、不同浏览器或改变本地 HTML 路径，都可能影响存档可用性。推荐定期导出文件备份；存储失败会显示提示，不通过删除旧作品腾空间。
- 清空和重置需要确认；清空保留收获统计，重置清零收获，命名存档均不删除。两者仍可撤销。

## V0.5 性能结构

- **活动分块**：画布被切成 `10 × 10` 的小块；没有粒子运动或反应的区域会休眠。
- **唤醒机制**：粒子移动、材料绘制或反应会唤醒当前格子及相邻分块，避免边界变化被漏掉。
- **脏区渲染**：只更新发生变化的矩形区域，再通过 `putImageData` 的 dirty rectangle 提交给 Canvas。
- **性能 HUD**：页面底部显示 FPS、最近一段时间的平均更新耗时，以及活动分块数量。

```text
电流 + 金属 -> 金属带电 -> 相邻金属继续导电

```

## V0.9 细节升级

- 世界网格加密到 `360 × 220`，显示区域仍保持 `18:11` 比例，让单个像素更细、材料边缘不再过于粗糙。
- 花朵不再只是一个小光点，特效层会绘制六瓣花冠和明亮花心；草根仍保持细枝支撑的角色。
- 粉末和液体按网格缩放补偿单帧移动步数，沙子、水、盐和种子的屏幕下落速度保持稳定。
- 播种后的草茎提高初始能量并延长初始高度，花朵延迟到根茎长高后再沿分枝开放；花朵不会阻止草继续分枝，特效层增加绿色枝叶提示。

## 种子、草与花的形态规则

工具栏提供七种独立播种材料：普通种子、小树种子、霸王花种子、蘑菇孢子、仙人掌种子、柳树种子、红树林种子。在沙土、石头或平台上播种，让水接触种子即可发芽；仙人掌还可以在干燥的沙地或平台上缓慢发芽。撒在水中的种子会先下沉，找到承托面后发芽。同类相连种子团合并成一个发芽点，不会把不同种类的种子一起吸收。

蘑菇只长一条约 8～11 格的奶油色菌柄，随后斑点菌盖由小到大逐渐展开；有红褐、赭黄、淡紫三种配色，菌盖半径为 7～10 格，不会无限增殖。仙人掌主干逐节长到 32～44 格，少量浇水可加快生长并额外增加最多 6 格高度、少许粗度；两条交错侧臂先向外再向上，有纵向亮纹和浅色小刺，整株仍受屏幕高度上限约束。新植物使用现有植物材料的燃烧、腐蚀规则，生长状态支持撤销和存读档。

普通种子初始分化 3～4 条枝，每条枝记录独立的生长顶端、方向和目标高度。第一轮花开放后，浇水可唤醒原枝端继续伸长约 10～16 格，再开第二轮花，保留旧花；每条枝最多两轮，根茎不越过屏幕顶部以下 1/4 的高度线。普通花具有不同花形、花色和固定的随机大小。

小树使用独立的树干、分枝、树冠生长逻辑；霸王花沿用逐节长茎和渐进开花流程，但使用更低的初始开花高度、宽叶和独立的大花绘制。植物种类与生长进度一同保存，并支持撤销、存档和读档。

普通果树的树冠完全展开后才进入结果阶段，青果在 450 个模拟帧内逐渐成熟，在总果龄 1500～1799 帧时脱落，因此成熟后还能挂果 1050～1349 帧；落果继续保留 1200～1800 个模拟帧，最后变褐淡出。叶片被移除时仍立即落果。旧存档读取时迁移果龄，已有熟果不会退回青果。果实不是独立绘制工具。每个叶簇的结果计数、整株总量以及果实成熟/落地后的剩余寿命都会随世界存档与撤销恢复，实际等待时间受模拟速度和帧率影响。

柳树和红树林是游戏中的耐湿观赏树，沿用树干、侧枝避障与存档规则，不结采集用树果。柳树叶色浅绿、侧枝叶簇更长，适合岸边与浅水；红树林树高较低、叶簇较宽、叶色更深，更耐深水积水。需要采果时请种植原来的小树种子。这些数值为游戏规则，不是现实植物耐涝数据。

## 避障与积水枯萎

- 树干和侧枝前方受阻时，先尝试上方空位，再在左右 24 格、下方 4 格的局部范围内寻找绕行路线，逐格沿障碍边缘生长。路线被新障碍挡住时重新规划；局部无通路时暂停并定期重试，不穿墙，也不会因为一次受阻就提前结成树冠。树高上限仍保留，过大或完全封闭的障碍不能保证绕过。
- 五类植物都根据根部上方 7×7 范围的实际积水判断过湿：至少 12 格水、至少 4 行各有 2 格水才计入持续积水。普通花、小树和霸王花连续积水 300 个模拟帧后开始黄化，仙人掌更敏感（195 帧），蘑菇更耐湿（450 帧）；浅水和短暂浇水不会直接枯萎。
- 黄化后生长放慢，枯萎达到 45% 时停止生长、开花和继续吸水；持续积水会在另 240 帧内完全枯死，花叶先凋落、根茎随后逐步消失。完全枯死前排水可以逐渐恢复，完全枯死后不能靠浇水复活。这里的帧指模拟更新，等待时间随速度与实际帧率变化。积水压力、枯萎程度和避障路线都随存档与撤销保存。
- 柳树在根部取样区域至少 24 格水、5 行各有至少 2 格水时才累计过湿压力，耐受时间为普通植物的 4 倍；红树林分别为 34 格水、6 行、8 倍。超出各自耐受范围仍会枯萎。
- 持续积水压力达到黄化阈值的 70% 时弹出非阻塞排水提示，合并当前受涝株数；可关闭，或点击按钮选橡皮擦手动清理水、打开挡水障碍。不会自动删水、暂停模拟或强制改动世界。同株在本次受涝中不反复弹窗，排水并基本恢复后再次受涝才会重新提醒；读档、撤销和重置会关闭旧弹窗。
